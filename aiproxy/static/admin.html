protections

  • the admin token is swapped for a session that lives only in a secure, http-only, same-site cookie. page scripts, extensions reading the page and the browser console cannot read it.
  • only this page's own script and styles run, pinned by hash. nothing loads from any other domain, and text can never turn into code.
  • changes are accepted only from this page on this domain. another site cannot make your browser send them.
  • the dashboard answers only on its own domain and, if set, from allowed ip addresses. everywhere else it does not exist.
  • sessions lock after inactivity, end within hours at most, and die when the browser changes.
  • wrong tokens are slowed to a few tries a minute per address and written to the ledger.
  • new api keys are shown once, hidden again after 90 seconds, and stored only as a hash.
